# MK3 migration checks

Run from the repository root:

```sh
pnpm run contributions:check
pnpm run check:mk3-boundaries
pnpm run check:ported-libraries
pnpm run completion:report
```

The quick and owner test tiers run these gates. `completion:report` prints a Markdown inventory
of actual legacy imports and every registered codec/provider not declaring `supported`, with its
declared limitations. Reported capability status does not replace installed-app acceptance.

## Legacy import ratchet

`mk3-legacy-imports.json` records exact remaining file/specifier/import-kind/count combinations,
with a migration owner and replacement direction. New imports fail; removing an import or reducing
its count also requires removing or shrinking its baseline entry. There is no automatic update mode.
The baseline acknowledges unfinished migration, and must never be described as zero legacy.

The TypeScript AST scanner covers production JavaScript/TypeScript in registered extensions'
`modules/` and `shared/`: static, side-effect, type, re-export, CommonJS, dynamic and JSDoc imports.
Ordinary comments and documentation strings do not count. Tests, scripts and build outputs are
excluded. Unresolved computed imports fail unless their exact expression and complete source hash
have an explicit owner/reason review. Changes to that source require a fresh review.

This is a direct import gate. It does not prove transitive closure through external package exports,
tsconfig aliases or arbitrary loader aliases, nor inspect the remaining historical `src/` trees.
Those, package contents and UI parity remain separate completion work.

## Canonical owner and contribution checks

`module-map.json` maps registered contributions to their intended package/module locations;
`module-map.inventory.json` is generated by `contributions:emit`. Image operations belong to
`starcraft2/modules/textures/providers/image-operations`.

The MK2 copies are gone; MK2 stays readable in `references/modkitmk2`. The Map receipt
`starcraft2/modules/map/MK3-MIGRATION.json` records which authorities moved into the Map module.
