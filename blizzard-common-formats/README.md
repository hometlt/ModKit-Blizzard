# blizzard/common-formats

Blizzard common-format codecs maintained in the standalone Blizzard extension repository.
The implementation was hand-ported from the Modkit MK2 extension and uses MK3 contribution
manifests and runtime contracts. Historical conversion receipts remain in the archived source
workspace and are intentionally excluded from this runtime package.

| contribution      | module             | status  |
| ----------------- | ------------------ | ------- |
| `blizzard/blp` | `src/blp/codec.js` | partial |
| `blizzard/s2protocol-provider` | `modules/s2protocol/index.js` | supported |
